# NEO-LIB v1.8.9 — Missing artwork crash hotfix

- Fixed a crash when opening games without artwork, including newly added Wizard entries.

## Windows installer rebuild

The installer remains **NEO-LIB-Setup.exe**. Existing v1.8.8 clients can discover
v1.8.9 through normal update checks or Settings → Updates. Nothing installs
automatically. Builds remain unsigned.

## Carried-forward features

Includes v1.8.8 functionality. This isolated hotfix does not include the unpublished
cursor, texture, News or layout-editor additions. Library data is not reset.
[Previous release notes](RELEASE_NOTES_v1.8.8.md).

## Release status

Publish only after the clean v1.8.9 Windows build passes packaging and candidate
inspection, with all four release assets uploaded. Hands-on installed acceptance
is tracked separately in [Windows acceptance](WINDOWS_ACCEPTANCE_V1.8.9.md).

Stable download: https://github.com/fufugis/Neo-Lib-Launcher/releases/latest/download/NEO-LIB-Setup.exe
