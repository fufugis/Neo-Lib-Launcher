# NEO-LIB — Top 10 Major Features (since v1.0)

> Curated highlights list, not a bug-fix log. Marketing-ready.

1. **🔒 Hidden category with PIN lock** — NSFW / private games disappear from
   the sidebar on startup and require a PIN to reveal. The reason NEO-LIB
   was built in the first place.

2. **🎯 Unified launcher auto-detection** — one-click imports from Steam,
   Epic, GOG, EA App, Ubisoft, Battle.net, Riot, Xbox / MS Store, itch.io.
   Games launch through their original executables, so achievements /
   overlays / cloud saves keep working.

3. **🧠 Multi-source metadata picker** — dedicated buttons for **Steam · GOG
   · itch.io · DLsite · VNDB · Ryuugames · F95Zone · Google · Ask AI**,
   results carousel with arrows and "N/M" counter. Finally finds indie and
   Japanese games.

4. **🗂 Smart Auto-Sort + custom categories** — one click buckets your
   library into *Recently Played · Long Games · Quick Sessions · AAA ·
   Indie · Hidden Gems*. Make your own categories, drag games between them,
   pin favorites to the top.

5. **🎨 8 dynamic themes + ambient effects + sound packs** — Synthwave,
   Midnight, Ocean, Crimson, Anime, Gaming, Modern, Mint Garden. Each with
   its own particles, CRT boot animation, and UI sound pack.

6. **🧙 Smart Wizard + drag-drop imports** — point at a folder or drive,
   auto-scans with Fast (5-deep) or Deep (10-deep) mode, dedupes against
   existing games, fetches metadata, previews each result before commit.
   Drag any folder onto the window to trigger it instantly.

7. **✨ Customize panel** — one prominent button on every game page lets
   you replace cover, icon, hero, background, screenshots, description,
   even the `.exe` NEO-LIB launches, all from a single side-by-side form.

8. **💬 Discord Rich Presence** — launching a game shows "Playing X · via
   NEO-LIB" in your Discord status. Free word-of-mouth every time you play.

9. **🧹 Tidy up — duplicate finder** — scans for same-exe, same-normalized-
   name, and multiple-.exes-in-same-folder-tree clusters. Side-by-side
   compare, keep one, remove the rest (files on disk untouched).

10. **🛒 Non-intrusive Live Deals strip** — Epic Free Games + Steam discounts
    + Instant Gaming hot deals, refreshed on launch. Featured banner
    showcases one deal at a time, "All N" pill opens the full grid.
    Dismissible per-session. Affiliate-tagged so it funds updates without
    ever feeling pushy.
