# Library 3D graphics

Three additional full-height material surfaces—Carbon Weave, Obsidian Slate and
Hammered Titanium—are documented with original prompts and asset processing in
[material-textures.md](material-textures.md). They use the same opacity/None controls.

## Full-height Library textures

Star Trails, Dragon Sketches and Retro Doodles were generated with the built-in image tool as 1024×1536 transparent portrait assets. Their PNG originals are retained, full-size WebP files keep alpha, and 160px thumbnails serve the picker. These three use 100% × 100% sizing over the entire Library backdrop: no uncovered strip or cropped top/bottom; proportions adapt to the panel. Shared opacity and None remain available. Shooting-star trails are static artwork, not animation.

Quiet cosmic atmosphere, restrained luminous highlights, no planets or characters. Static finished illustration.

Retro Doodles: Use case: stylized-concept. Asset type: portrait transparent texture for a vertical PC game-library panel. Tall 2:3 portrait composition, artwork distributed evenly from the very top to the very bottom and across the width, not a central sticker or isolated cluster. Subtle decorative detail behind readable game lists. Genuine transparent background, no opaque rectangle or paper backdrop. No words, logos, UI or watermark. Subject: Retro Doodles. Hand-sketched vintage gaming objects scattered over the entire tall canvas: generic arcade cabinets, joysticks, old handheld consoles, cassette tapes, floppy disks, CRT monitors, pixel-inspired stars and geometric scribbles. Created with the built-in image generation tool for NEO-LIB Visuals. All three PNG originals are 1672×941, have alpha, and are preserved here. Full-size WebP copies preserve transparency; 240px WebP thumbnails are used only by the picker. No asset is a live 3D scene or animation. The chosen graphic uses the existing Library background opacity and None controls; it cannot intercept input or paint above text/hero screenshots.

## Final prompt set

Use case: stylized-concept. Asset type: transparent decorative backdrop for a PC game library, NOT a UI mockup. Wide landscape composition. Premium high-detail 3D render, tasteful cyan/violet and silver highlights on dark glossy surfaces. Large quiet transparent negative space so foreground game lists remain legible. No text, logos, characters, UI, borders, opaque rectangular background, or watermark. Genuine transparent background, isolated shapes fading naturally into transparency. Soft lighting, no huge blown-out white highlights.
