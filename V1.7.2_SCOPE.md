# NEO-LIB v1.7.2 — active scope

## Home discovery and game identity

- Add a Home pane that surfaces only notable games released in the last seven days.
- Use a quality filter designed to reject low-visibility releases: the initial implementation uses recent player-interest signals, then verifies each candidate's official store release date and game type.
- Each card shows cover art, title, platform/source, release date, and a transparent “Why it is here” signal.
- Refresh automatically from a six-hour cache, with a manual refresh control. No silent background drive scans or account access.
- Open the official store page externally when the user selects a title.
- If no strict major title qualifies, show a clearly-labelled semi-major fallback with verified early momentum instead of leaving the pane blank.

## Metadata and genre repair

- Maintain a direct-source, exact-match game identity profile for core genres, subgenres, playstyle, perspective, and themes. This remains separate from personal Library categories.
- Show the identity profile as green **NEW** information in the folder Wizard and the normal metadata approval flow before a game is changed.
- Let Tidy Up run an approval-first repair queue for every game with no identity, using safe local title clues from the executable, nearby folders, and bounded README/title fields. Track repaired/skipped progress and allow the review to stop at any time.

## Preview polish

- Keep Launch prominent, group supporting game actions into a compact menu, show genres in a theme-responsive vertical identity card, and present game facts as a readable list.

## Update Intelligence foundation

- Read concrete pending Steam download bytes from installed app manifests and surface them in Home and the selected game preview.
- Keep the integration read-only and hand control to Steam Downloads; never modify a launcher queue or infer an update from an ambiguous state flag.
- Allow independent games to store an installed version and a user-chosen public update page; alert only when an explicit higher Version/Build/vX.Y label is found and link back to the source.
- Present detected independent-game patch entries in a read-only in-app history view, including dates when the source exposes them and clear markers for versions newer than the installed copy.

## Launcher adapters

- Promote GOG from a placeholder to a native installed-game import using local Windows registry records, bounded executable selection, GOG identity preservation, and launcher-category creation.
- Promote EA App/legacy Origin from a placeholder to a native local import using Windows installation records, product/version preservation, bounded executable selection, deduplication, and launcher-category creation.
- Promote Ubisoft Connect from a placeholder to a native local import using installed-game registry records, product/native-launch preservation, bounded executable selection, deduplication, and category creation.
- Promote Battle.net from a placeholder to a native local import using verified Blizzard installation records, desktop-client exclusion, product/version preservation, bounded executable selection, deduplication, and category creation.
- Promote Riot from a placeholder to a native local import using bounded product metadata, client exclusion, product/version/configured-executable preservation, deduplication, and category creation.
- Promote Xbox/Game Pass from a placeholder to a native local import using bounded XboxGames roots and per-title MicrosoftGame.config files, with Store/configured-executable identity and category preservation.
- Promote Rockstar from a placeholder to a native local import using verified Windows installation records, launcher/support exclusion, product/version preservation, bounded executable selection, deduplication, and category creation.
- Add a safe itch.io local import that reads only the desktop client’s explicitly configured install locations and completed-install receipt markers. Keep the live itch catalog database untouched; folder-derived names must still enter the normal approval-first metadata flow.

## Explicitly out of scope

- Discord presence/mirroring.
- Friends-list scraping or chat mirroring.
- Remaining Update Intelligence research: non-Steam launcher queues where a client exposes a reliable read-only local signal.
- Broader launcher adapters and non-Steam discovery sources.
