# NEO-LIB v1.7.2 — active scope

## Released This Week

- Add a Home pane that surfaces only notable games released in the last seven days.
- Use a quality filter designed to reject low-visibility releases: the initial implementation uses recent player-interest signals, then verifies each candidate's official store release date and game type.
- Each card shows cover art, title, platform/source, release date, and a transparent “Why it is here” signal.
- Refresh automatically from a six-hour cache, with a manual refresh control. No silent background drive scans or account access.
- Open the official store page externally when the user selects a title.

## Explicitly out of scope

- Discord presence/mirroring.
- Friends-list scraping or chat mirroring.
- Metadata recovery, update intelligence, and broader launcher adapters. These can be re-added only if requested after v1.7.2 is reviewed.
