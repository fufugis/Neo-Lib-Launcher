# NEO-LIB v1.8.8 — Sidebar and Categories hotfix

- Categories opens above the sidebar and stays inside the window.
- Sidebar saturation affects only icons and colored borders—not backgrounds or text.
- Icons only previews the compact layout while you adjust sliders.
- Large sidebar icons stay centered, including Add games.
- Icons-only hover and keyboard labels show the name with its subtext underneath.

## Windows installer rebuild

The installer remains **NEO-LIB-Setup.exe**. Version and checksum records identify
v1.8.8. Existing users can use Settings → Updates; awake clients also check hourly.
Nothing installs automatically. Builds remain unsigned.

## Carried-forward features

Includes all 1.8.7 functionality. This is a focused hotfix, not a repeat of those
features as new additions. [Previous release highlights](RELEASE_NOTES_v1.8.7.md).

## Release status

Publication requires a successful clean-tag v1.8.8 build, inspected installer and
portable ZIP, and all four verified assets. Installed interaction checks are tracked
separately in [Windows acceptance](WINDOWS_ACCEPTANCE_V1.8.8.md).

Stable download: https://github.com/fufugis/Neo-Lib-Launcher/releases/latest/download/NEO-LIB-Setup.exe
