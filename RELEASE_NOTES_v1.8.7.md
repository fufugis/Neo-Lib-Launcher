# NEO-LIB v1.8.7 — Home, Lounge and personalization

## Main additions

- **Home layout editor:** Move, resize and park Home widgets; extend page height and scale content. Lounge adds grouped Visuals, compact FX, custom themes, pinned previews and cover/info heroes.
- **Game-preview layout editor:** Rearrange and resize section boxes; content reflows at normal text size instead of shrinking the whole preview.
- **Playtime calendar:** Month/year heatmaps for Home and Lounge, with game filters and recorded daily playtime.
- **News and mail inbox:** Team announcements appear once as a popup and remain in your inbox until deleted.
- **Automatic idle power saver:** After 15 quiet minutes, pauses expensive visuals while keeping mascot announcements available.
- **New welcome and tutorial:** Guided setup or exploration, a refreshed tutorial, optional 16+ usage reporting and privacy notice. Permanent sidebar navigation and a simpler tabbed Wizard.
- **Community widget coding guide:** Import widget includes starter files and clear format, API, permission and capability guidance.
- **Update popup and download:** New GitHub releases show a download prompt even when the mascot is disabled.
- **Retro emulator setup:** Add emulators and ROM folders row by row, track time per ROM and optionally exclude ROMs from statistics.
- **Library background graphics:** Three 3D graphics, full-height textures, Ember/Camo artwork and object-shaped Industrial, Future and Stoneage cursors. Custom Lounge stills keep originals and scene effects.

## Windows installer rebuild

The installer remains **NEO-LIB-Setup.exe**. Internal version and checksum records identify v1.8.7. Existing users can check from Settings → Updates; the new build also checks hourly while awake and offers a download popup.

## Carried-forward features

Includes the existing unified Library, official Lounge module, addons, playtime pie, retro integrations and original high-resolution themes.
